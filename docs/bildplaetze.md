# أماكن الصور (Bildplätze)

كل مكان صورة في الموقع ينتظر ملفاً باسم محدد داخل المجلد `img/shots/`.
ضع الصورة بنفس الاسم بالضبط (بصيغة `.jpg`) ثم شغّل `python3 src/build.py` واعمل commit — تظهر الصورة تلقائياً مكان الإطار المنقّط.
طالما الملف غير موجود يظهر إطار ذهبي منقّط مكتوب فيه ماذا يجب أن تكون الصورة واسم الملف.

> نصيحة: اجعل الصور بإضاءة دافئة وألوان كحلي / عاجي / ذهبي حتى تتناسق مع البالتة الجديدة. الحجم الأقصى المفضّل لكل صورة ≈ 300 KB.
