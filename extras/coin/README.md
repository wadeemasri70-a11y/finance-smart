# عملة Smart Finance الذهبية (3D)

العملة اللي كانت بأول الموقع، محفوظة هون لحالها لتستعملها وقت بدك.

- `coin.html`: صفحة كاملة لحالها. افتحها بالمتصفح وبتشوف العملة عم تتحرك.
- `fonts/`: الخطوط اللي بتستعملها الكتابة عالعملة. خلّيها جنب `coin.html`.

## لترجّعها عالموقع
1. انسخ من `coin.html` الكود اللي بين `/* ============ Münze (3D) ============ */` و `</style>` وحطه بالـ CSS تبع الموقع.
2. انسخ بلوك `<div class="coin-wrap"> … </div>` وحطه بالمكان اللي بدك ياه بالصفحة.
3. رمز اللوغو (`<symbol id="sfmark">`) موجود أصلاً بالموقع، فما في داعي تنسخه.

حجم العملة بيتغير من المتغيّر `--d` على `.coin-stage`، مثلاً: `.coin-stage{--d:300px}`.
